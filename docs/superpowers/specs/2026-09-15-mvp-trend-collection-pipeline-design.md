# MVP 트렌드 수집 파이프라인 — 설계 스펙

**작성일**: 2026-09-15
**관련 문서**: [PRD.md](../../../PRD.md)

## 배경

PRD 기준 핵심 기능 1번(콘텐츠 자동 수집)의 1차 MVP 하위 프로젝트. X·인스타그램 공식 API는 무료로 트렌드 검색이 사실상 불가능(X는 읽기 권한이 유료 티어부터, Instagram Graph API는 본인 계정 데이터 위주)하다고 판단되어, MVP는 Reddit + RSS 피드를 대체 데이터 소스로 사용한다. 대시보드·슬랙 리포트·브랜드 콘텐츠 변환 제안은 별도 하위 프로젝트로 이후 진행한다.

## 범위

- **포함**: Reddit 수집, RSS 수집, Claude API 기반 키워드 추출, SQLite 저장, 수동 실행 파이프라인
- **제외 (후속 하위 프로젝트)**: 웹 대시보드, 슬랙 알림, 자동 스케줄링(Task Scheduler), X·인스타그램 API 연동, 브랜드 콘텐츠 변환 제안

## 아키텍처

```
[Reddit API]  [RSS 피드들]
      \          /
       ▼        ▼
   수집 스크립트 (Python, 수동 실행)
              │
              ▼
     Claude API (키워드 추출)
              │
              ▼
         SQLite DB
   (원본 콘텐츠 + 추출 키워드 + 활용 아카이빙)
```

하루 1회 사람이 스크립트를 실행하면, Reddit(마케팅/소셜미디어/일반 트렌드를 아우르는 넓은 범위 서브레딧)과 RSS 피드에서 최근 콘텐츠를 모으고, 반응이 급등한 것 위주로 걸러낸 뒤 Claude API로 키워드를 뽑아 SQLite에 쌓는다.

## 컴포넌트

| 파일 | 역할 |
|---|---|
| `reddit_collector.py` | PRAW로 지정 서브레딧에서 최근 24시간 게시물 수집. 업보트·댓글 수가 해당 서브레딧 최근 평균 대비 급등한 것만 필터링 |
| `rss_collector.py` | 등록된 마케팅 RSS 피드 목록을 순회하며 마지막 실행 이후 신규 항목만 수집 |
| `keyword_extractor.py` | 수집된 원문(제목/본문/요약)을 Claude API에 보내 핵심 키워드 3~5개 + 활용 맥락 한 줄 요약 추출 |
| `storage.py` | SQLite 스키마 관리(`raw_content`, `keywords` 테이블) 및 저장/조회 함수 |
| `run_pipeline.py` | 위 컴포넌트를 순서대로 실행하는 수동 진입점 스크립트 |

각 컴포넌트는 독립된 책임을 가지며, 다른 컴포넌트 구현에 의존하지 않고 함수 단위로 교체·테스트 가능해야 한다.

## 데이터 흐름 & 에러 처리

1. `run_pipeline.py` 실행 → Reddit 수집과 RSS 수집은 서로 독립적으로 실행 (한쪽 실패가 다른 쪽에 영향 주지 않음)
2. 수집 실패 시(네트워크 오류, API 키 문제 등): 해당 소스만 건너뛰고 로그에 실패 사유 기록, 파이프라인 전체는 중단하지 않음
3. 수집된 콘텐츠를 Claude API로 배치 처리하여 키워드 추출
4. Claude API 호출 실패 시: 해당 콘텐츠는 키워드 없이 원문만 저장, 재시도는 강제하지 않고 다음 실행에서 자연히 커버
5. 모든 저장 결과를 SQLite에 반영

## 검증 (실행 결과 요약)

매 실행 끝에 다음 형태의 요약을 콘솔에 출력한다 — 이는 개발 과정에서 "완료했다"는 주장을 실제 수치로 뒷받침하기 위한 최소 검증 장치다.

```
Reddit 수집: N건
RSS 수집: M건
키워드 추출: 성공 K건 / 실패 F건
```

## 테스트 방식

- 각 컴포넌트(수집기, 키워드 추출기, 저장소)는 함수 단위로 작성하여 실제 API 호출 없이 가짜 데이터로 로직 검증 가능해야 한다
- 통합 확인은 실제 스크립트를 1회 실행해 SQLite에 데이터가 쌓이는지 수동으로 확인하는 것으로 한다

## 제약 및 사전 준비 사항

- Reddit API 앱 등록(클라이언트 ID/시크릿) 필요 — 개인 소규모 사용은 즉시 무료
- Claude API 키 필요 (키워드 추출용, 사용량에 따른 소액 비용 발생)
- 실행 환경: Python, 로컬 실행(1인 사용), 스케줄링 없이 수동 실행
